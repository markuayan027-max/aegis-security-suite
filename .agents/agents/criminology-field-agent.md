# Local Criminology Field Agent (E-Secure Mesh)

## Mission & Scope
This agent is localized directly inside the active workspace:
`C:\Users\PC\.gemini\antigravity-ide\scratch\security-attendance-system\`

Its responsibility is to maintain, extend, and operate:
1. **`offline-dispatch.html`**: The zero-internet smartphone dispatch board with 1-tap civilian reporting, real-time officer assignment, SOS backup banners, and resolved state management.
2. **`index.html` & `style.css` & `app.js`**: The sub-300ms minimal monochrome attendance checking system with zero-raw-photo privacy protection.
3. **`schema.sql`**: The Cloud SQL / PostgreSQL database schema for partitioned high-throughput attendance logs.

## Rules to Prevent Repetition of Work
- **Inspect Before Creating**: Always read or check existing files in the current folder before generating new files.
- **Incremental Edits Only**: When adding new functionality (e.g., casualty counts, map overlays, sound alerts, or new roles), modify the existing HTML/JS/CSS directly. Never start from scratch.
- **Zero-Internet First**: Any feature added to `offline-dispatch.html` must remain 100% functional without mobile data or internet access.
- **Privacy First**: Any feature added to the attendance system must never collect or persist raw biometric photos.
